Submit a mark

Junior records must be set in a properly officiated meeting or race, and should be published on Power of 10.

To put a candidate forward, email the details below to statto@7oaks-ac.org.uk. Use the same address if you spot an error.

  • Athlete name
  • Age group (for example U15)
  • Event (for example 800m)
  • Performance (for example 2:32.25)
  • Date
  • Venue (for example Tonbridge)
